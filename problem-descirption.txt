I want to build a project for detecting vulnerable code using an unsupervised method.

## Initial Idea

For each function or code snippet:

1. We have the original code and its docstring or documentation.
2. We provide only the documentation to an LLM, without exposing the original code.
3. We ask the LLM to generate a new implementation based only on the documentation.
4. We provide both the original code and the generated code to another LLM that acts as a judge.
5. The judge analyzes the differences and assigns a score, for example from 1 to 10, based on their semantic and behavioral similarity.
6. A significant mismatch between the behavior described in the documentation and the original code may indicate a bug, a deviation from the specification, or a potential vulnerability.

Important: Do not automatically assume that syntactically different code is vulnerable. Two different implementations may perform exactly the same operation. The comparison should focus on behavior, edge cases, input validation, error handling, and security aspects—not only textual similarity.
